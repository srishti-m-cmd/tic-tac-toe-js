# 🎮 Tic Tac Toe Game (HTML + CSS + JavaScript)

A fun and interactive *Tic Tac Toe* game built using *HTML, **CSS, and **JavaScript*.  
This project focuses on DOM manipulation, game logic, and responsive UI.

---

## 🚀 Features

- ✨ Two-player gameplay  
- 💡 Real-time win/tie detection  
- 🔁 Restart/Reset game button  
- 🎨 Simple, clean, and responsive design  
- 🧠 Logical implementation using condition checks and arrays

---

## 🧠 What I Learned

- Handling *user interactions* and DOM events  
- Using *JavaScript logic* to determine win/tie states  
- Updating the UI dynamically  
- Writing clean and modular JavaScript code
